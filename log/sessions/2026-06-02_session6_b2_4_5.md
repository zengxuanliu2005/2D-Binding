# Session 6 — B2.4 + B2.5

## What we did

Two derivation steps, each with 5 standard md files (00 intent / 01
setup / 03 result / 04 numerics / 05 open questions) and a standalone
production script in `scripts/`.

### B2.4 — ξ_RL = σ_K2D + Xu 2015 ratio test

`scripts/xi_rl_lp_prediction.py`:
- Reads B2.2's 200 K z_lab samples per system
- Bootstraps σ_K2D via independent (z_R, z_L) index resampling
- n_boot = 200, n_jobs = 8 → 40 s wall

Critical fix vs B2.3: derivation/03 used paired draws (z_R = z_L from
same index), which inflates σ_K2D by √2 for symmetric R-L systems.
B2.4 uses **independent index sets** — the correct
P_z^R × P_z^L convolution. Recorded numbers:

| system | σ_K2D (B2.4, ind.) | σ_K2D (B2.3, paired) | measured ξ_RL |
|---|---:|---:|---:|
| rigid | 1.110 ± 0.002 nm | 1.42 | 0.685 |
| semi  | 3.919 ± 0.006 nm | 5.45 | 2.076 |
| flex  | 2.840 ± 0.005 nm | 3.91 | 2.253 |

Absolute over-prediction shrinks from 1.7-2.6× (B2.3) to 1.3-1.9×
(B2.4), confirming the √2 paired-draw artifact for rigid (B2.3 ratio
1.42/1.11 = 1.28).

### Ratio test (lp discrimination signature)

| ratio | B2 ± boot σ | Xu 2015 | measured | B2 err | Xu err |
|---|---:|---:|---:|---:|---:|
| rigid:flex | 0.391 ± 0.001 | 1.000 | 0.304 | 28.5% | **228.9%** |
| rigid:semi | 0.283 ± 0.001 | 0.999 | 0.330 | 14.2% | **202.7%** |
| semi:flex  | 1.380 ± 0.003 | 1.001 | 0.921 | 49.8% | 8.7% |

**Verdict**: B2 beats Xu by 8× on rigid:flex and 14× on rigid:semi —
the two ratios where lp differs by ≥ 10×. The semi:flex inversion is
the z<0 truncation artifact already documented in derivation/03 05 Q2;
not new.

The Xu 2015 result is structurally guaranteed to be ≈ 1.00 across all
three pairs because k_a is identical (257 / 252 / 257 ε/rad², varying
< 2%). Any chain-based theory that distinguishes lp wins automatically.

### B2.5 — F_conf via -ln P_z(D_bound)

`scripts/fconf_b2_selfconsistency.py`:
- Reads B2.2's z_lab samples and B1's D_bound values (9.154 / 7.964 /
  6.615 nm for rigid / semi / flex)
- Histograms z_lab (200 bins), linearly interpolates at D_bound,
  computes F_conf = −ln P_z(D)
- n_boot = 200 × 3 systems × 8 jobs → 1.1 s wall (histogram is fast)

Per-system result vs B1 Marko-Siggia:

| system | D_bound (nm) | F_conf^(B2) ± σ | F_conf^(MS, B1) | Δ_anchor |
|---|---:|---:|---:|---:|
| rigid | 9.154 | +3.913 ± 0.075 | +0.128 | **+3.785** |
| semi  | 7.964 | +2.015 ± 0.015 | +0.803 | +1.212 |
| flex  | 6.615 | +3.337 ± 0.034 | +3.381 | −0.044 |

**Anchor-cone surcharge** Δ_anchor decomposes F_conf cleanly:

```
F_conf^(real) ≈ F^(MS, stretch) + Δ_anchor(orientation)
```

- For flex (lp = 1.14 nm ≪ Lc = 12 nm), chain internal entropy
  dominates → anchor cone invisible → MS captures F_conf to within
  0.05 kBT.
- For rigid (lp = 84.6 nm ≫ Lc = 12 nm), anchor cone is the dominant
  constraint → MS undercounts F_conf by **30×**.

This was unexpected before running B2.5. It explains why MS is a
"good-enough" F_conf for flex (PPT s25 closure works there) and a
gross under-estimate for rigid (closure budget cannot balance).

### Cross-pair ΔΔF_conf

| pair | ΔΔF^(B2) | ΔΔF^(MS, B1) | ΔΔF_sum^(PPT s25) |
|---|---:|---:|---:|
| flex − rigid | −0.576 | +3.253 | +3.640 (= total target) |
| semi − rigid | −1.898 | +0.675 | +2.470 |
| semi − flex  | −1.322 | −2.577 | −1.180 |

B2 and MS **disagree in sign** on flex−rigid and semi−rigid pairs
because Δ_anchor(rigid) ≫ Δ_anchor(flex,semi) flips the ordering.
Substituting B2 for MS in the B1 closure makes the closure
**under-shoot** the PPT target — opposite direction from B1's overshoot.
Neither closure hits the target; deeper investigation (cluster
constrained-h MD, σ_p convolution, trans+rot re-derivation) deferred.

## Key findings / numbers

1. **B2.4 absolute σ_K2D corrected**: 1.110 / 3.919 / 2.840 nm
   (independent draws, vs B2.3's 1.42 / 5.45 / 3.91 paired draws).
2. **B2 ratio test beats Xu 2015 by 8-14×** on the two non-trivial
   ratios (rigid:flex, rigid:semi).
3. **Anchor-cone surcharge Δ_anchor** is monotone with lp:
   +3.79 / +1.21 / -0.04 kBT (rigid / semi / flex). Headline result of
   B2.5.
4. **Bootstrap σ on both predictions** is small (< 0.5% relative
   on σ_K2D, < 0.1 kBT on F_conf) — n_boot = 200 sufficient.

## Decisions made

- B2.4 uses independent (z_R, z_L) draws (correct convolution); B2.3's
  paired-draws values stay archived in derivation/03 but are marked as
  "superseded by B2.4" in log/calibration/b2_vs_measured_xi_rl.md.
- F_conf^(B2)(D) defined as -ln P_z(D) with P_z normalised per nm. The
  log offset cancels in cross-pair ΔΔF.
- B2.5 uses 200-bin histogram + linear interp (not KDE). Rationale in
  derivation/05 04_numerics.md.
